立即執行步驟（按順序）
========================================

【步驟 1】啟動後端
------------------
1. 開啟 PowerShell
2. 執行：
   cd C:\Users\Administrator\Desktop\SmartClosetAI
   .\start.ps1

3. 看到這個訊息就成功了：
   "INFO:     Uvicorn running on http://0.0.0.0:8000"

【步驟 2】啟動前端
------------------
1. 開啟另一個 PowerShell 視窗
2. 執行：
   cd C:\Users\Administrator\Downloads\smart-clothes-main\smart-clothes-main
   .\start_frontend.ps1

3. 看到這個訊息就成功了：
   "VITE ... ready in ... ms"
   "➜ Local: http://localhost:5173/"

【步驟 3】使用修復工具
------------------
1. 在瀏覽器開啟：
   http://localhost:5173/fix.html

2. 點擊「🚀 一鍵自動修復」

3. 等待修復完成（約 3 秒）

4. 自動跳轉到首頁

【步驟 4】重新登入
------------------
1. 在首頁點擊「登入」
2. 輸入用戶名和密碼
3. 登入成功！

========================================
如果還有問題
========================================

問題 1：後端啟動失敗
解決：
  cd C:\Users\Administrator\Desktop\SmartClosetAI
  pip install -r requirements.txt
  .\start.ps1

問題 2：前端啟動失敗
解決：
  cd C:\Users\Administrator\Downloads\smart-clothes-main\smart-clothes-main
  npm install
  .\start_frontend.ps1

問題 3：修復工具打不開
解決：
  確認前端已啟動，然後直接訪問：
  http://localhost:5173/fix.html

問題 4：登入後還是有問題
解決：
  1. 按 F12 打開開發者工具
  2. 切換到 Console 標籤
  3. 執行：
     localStorage.clear();
     location.reload();
