InsightFace 臉部交換模型 - 手動下載指南
═══════════════════════════════════════════════════════════

【問題】
❌ 自動下載失敗（Hugging Face 需要授權、網路問題）
❌ 模型文件已損壞（已刪除）

【解決方案】請使用瀏覽器手動下載

───────────────────────────────────────────────────────────
方法 1：從 GitHub Release 下載（推薦）
───────────────────────────────────────────────────────────

步驟：
1. 用瀏覽器打開以下連結：
   https://github.com/facefusion/facefusion-assets/releases/download/models/inswapper_128.onnx

2. 如果連結無法訪問，請訪問：
   https://github.com/facefusion/facefusion-assets/releases
   然後找到 inswapper_128.onnx 並下載

3. 下載完成後，將文件移動到：
   C:\Users\Administrator\.insightface\models\inswapper_128.onnx

───────────────────────────────────────────────────────────
方法 2：從百度網盤或其他雲端硬碟下載
───────────────────────────────────────────────────────────

如果 GitHub 無法訪問，可以：
1. 在百度搜尋："inswapper_128.onnx 下載"
2. 找到可靠的分享連結（注意病毒！）
3. 下載後放到上述路徑

───────────────────────────────────────────────────────────
方法 3：從 Hugging Face 下載（需要帳號）
───────────────────────────────────────────────────────────

1. 註冊 Hugging Face 帳號：https://huggingface.co/join
2. 登入後訪問：https://huggingface.co/deepinsight/inswapper
3. 找到 inswapper_128.onnx 並下載
4. 放到指定路徑

───────────────────────────────────────────────────────────
驗證步驟
───────────────────────────────────────────────────────────

下載完成後，在 PowerShell 執行：

# 檢查文件
$file = Get-Item "$env:USERPROFILE\.insightface\models\inswapper_128.onnx"
$sizeMB = [math]::Round($file.Length / 1MB, 2)
Write-Host "文件大小: $sizeMB MB"

# 正常大小應該是 530-560 MB
if ($sizeMB -gt 500) {
    Write-Host "✅ 模型正常！"
} else {
    Write-Host "❌ 文件過小，請重新下載"
}

───────────────────────────────────────────────────────────
重啟後端
───────────────────────────────────────────────────────────

模型下載完成後：

1. 停止當前後端（Ctrl+C）

2. 重新啟動：
   cd C:\Users\Administrator\Desktop\SmartClosetAI
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

3. 查看日誌，應該顯示：
   ✅ InsightFace 已導入
